# Beaverly — The World of Beavers

A responsive, English-language informational website introducing beavers, their adaptations, habitats, and ecological effects. Includes a small interactive quiz.

## Technologies
- HTML5 for semantic page structure
- CSS3 for responsive styling and the illustrated hero artwork
- Vanilla JavaScript for mobile navigation and the quiz

## Run locally
No build tools or dependencies are required. Open `index.html` in a modern browser, or serve this folder with a local static server.

## Deploy to Firebase Hosting
1. Install the Firebase CLI and sign in: `npm install -g firebase-tools` and `firebase login`.
2. From this folder, run `firebase use --add` and select the Firebase project you created for this site. The included `firebase.json` sets the public directory to `.`.
3. Run `firebase deploy --only hosting`.
5. Put your live Hosting URL here: `https://beaver-website-97621.web.app`.
